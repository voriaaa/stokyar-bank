# بانک سؤال آنلاین استوک‌یار

هر سؤالی که در پوشهٔ `sets` این مخزن باشد، خودکار به برنامهٔ استوک‌یار همهٔ دانش‌آموزها می‌رسد. برنامه هر ۶ ساعت یک بار خودش این مخزن را بررسی می‌کند و با دکمهٔ «دریافت سؤال‌های جدید» در بخش «تست» هم می‌شود همان لحظه به‌روز کرد. نصب نسخهٔ جدید برنامه لازم نیست.

## افزودن سؤال جدید

1. در برنامه وارد بخش مدیریت شو: «تنظیمات ← مدیریت سؤال‌ها».
2. متن سؤال‌ها را بچسبان، استخراج و بررسی کن و در یک بسته ذخیره کن.
3. در تب «بسته‌های من» روی «ذخیره در گوشی» یا «اشتراک‌گذاری» بزن تا فایل `.json` بسته را بگیری.
4. در گیت‌هاب وارد پوشهٔ `sets` همین مخزن شو، **Add file ← Upload files** را بزن، فایل را آپلود کن و **Commit changes** را بزن.
5. یکی دو دقیقه بعد، فهرست `index.json` خودکار به‌روز می‌شود (تب **Actions** باید تیک سبز بخورد).

اگر تیک قرمز خورد، یعنی فایل ایراد دارد. روی اجرای قرمز بزن تا ببینی کدام سؤال ناقص است. تا ایراد رفع نشود، سؤال‌های قبلی دست نمی‌خورند.

## اصلاح یا حذف

- **اصلاح:** فایل اصلاح‌شده را با همان اسم دوباره آپلود کن. پیشرفت دانش‌آموزها حفظ می‌شود، چون به شناسهٔ هر سؤال وابسته است.
- **حذف:** فایل را از پوشهٔ `sets` پاک کن. از برنامه‌ها هم حذف می‌شود.
- **اصلاح سؤال‌های داخلی برنامه:** اگر شناسهٔ (`id`) یک مجموعه با یکی از مجموعه‌های داخلی برنامه یکی باشد، نسخهٔ این مخزن جای نسخهٔ داخلی را می‌گیرد.
